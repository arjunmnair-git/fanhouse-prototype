# 🏟️ FanHouse

### Don't Watch Alone. Host the Stadium.

FanHouse is a sports fan-hosting platform that transforms living rooms
into ticketed fan venues, allowing sports fans to discover and host
shared live sporting experiences.

🔗 Live Demo: https://fanhouse-prototype.vercel.app

---

## 🚀 What It Does

FanHouse connects sports fans who want to watch major sporting events
together in a hosted, community-driven environment.

Users can:
- Discover upcoming sporting events
- Explore fan-hosting opportunities
- Host watch parties
- Browse sports categories
- Experience a ticketed venue-style fan experience
